## About

A community-maintained collection of 7.0 resources, built on top of the 6.1.0
work by pmagixc & Meowereal and the 6.5 base from kitkat.

> [!WARNING]
> This is an active WIP. Files may be incomplete, missing, or replaced without
> notice. Expect breaking changes until 7.0 is fully finalized.

## Usage

1. Download or clone this repository.
2. Drop the contents into your server's `resources` directory.
3. Restart the server.

```bash
git clone https://github.com/Merprose2/LunaGCR-Resources resources
```
